### 3. Теоретические сведения (кратко)

#### 3.1. Продвинутое использование `ids`

В лабораторной №4 мы узнали, что `ids` позволяет получить доступ к дочерним виджетам из Python. Но есть важные нюансы:

**Доступ к вложенным виджетам:**
Если виджет находится внутри другого контейнера, `ids` всё равно работает — Kivy собирает все `id` в один словарь `self.ids` корневого виджета правила.

```kv
<MyWidget>:
    BoxLayout:
        Label:
            id: nested_label
            text: 'Вложенный'
    
    # Доступ из Python: self.ids.nested_label
```

**Ограничения `ids`:**
- `ids` работает только для виджетов, определённых в **KV-файле**. Виджеты, созданные в Python через `add_widget()`, не попадают в `ids`.
- `ids` доступен только **после** инициализации виджета (не в `__init__`).

#### 3.2. Выражения и динамические привязки

KV-язык поддерживает **выражения** — значения свойств, которые автоматически пересчитываются при изменении зависимостей.

**Пример:**
```kv
<MyWidget>:
    Label:
        id: label1
        text: 'Привет'
    
    Label:
        # Текст автоматически обновится, когда изменится label1.text
        text: 'Вы сказали: ' + label1.text
        color: [1, 0, 0, 1] if label1.text == 'Привет' else [0, 1, 0, 1]
```

**Как это работает:**
Kivy анализирует выражение и находит все зависимости (`label1.text`). Когда любая зависимость меняется, выражение пересчитывается автоматически.

**Важно:** выражения должны быть **однострочными**. Для сложной логики используйте Python-методы.

#### 3.3. Привязки (Bindings)

Привязки — это механизм, с помощью которого Kivy отслеживает изменения свойств и обновляет зависимые значения.

**Автоматические привязки:**
Когда вы пишете в KV:
```kv
text: label1.text
```
Kivy автоматически создаёт привязку: при изменении `label1.text` свойство `text` текущего виджета обновится.

**Явные привязки в Python:**
```python
self.label1.bind(text=self.on_text_change)

def on_text_change(self, instance, value):
    print(f'Текст изменился на: {value}')
```

#### 3.4. Условные выражения в KV

В KV можно использовать тернарный оператор и логические выражения:

```kv
<MyWidget>:
    Button:
        # Цвет зависит от состояния
        background_color: [0, 1, 0, 1] if self.state == 'normal' else [1, 0, 0, 1]
        
        # Текст зависит от значения
        text: 'Включено' if root.is_active else 'Выключено'
        
        # Размер зависит от условия
        font_size: 24 if root.is_important else 16
```

**Ограничения:**
- Нельзя использовать многострочные `if/else`.
- Нельзя вызывать функции с побочными эффектами (только вычисления).

#### 3.5. Ссылки на родительские виджеты

В KV можно обращаться к родительским виджетам через `parent`:

```kv
<MyWidget>:
    BoxLayout:
        Label:
            # Размер шрифта равен ширине родителя
            font_size: self.parent.width / 10
            
            # Цвет зависит от позиции родителя
            color: [1, 0, 0, 1] if self.parent.x > 100 else [0, 0, 1, 1]
```

**Осторожно:** `parent` может быть `None`, если виджет ещё не добавлен в дерево.

#### 3.6. Вызов методов из KV

Можно вызывать методы Python-класса прямо из KV:

```kv
<MyWidget>:
    Button:
        text: 'Нажми'
        on_press: root.do_something()
        on_release: root.calculate(42, 'test')
```

В Python:
```python
class MyWidget(BoxLayout):
    def do_something(self):
        print('Метод вызван!')
    
    def calculate(self, number, text):
        print(f'Получено: {number}, {text}')
```
